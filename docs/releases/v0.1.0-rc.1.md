# OpenAgentFence v0.1.0-rc.1 — local candidate notes

This document describes a local, unpublished release-candidate assembly. It is
not an npm publication, a git tag, a GitHub release, a provenance statement, or
an approval to perform any of those actions.

The candidate packages the M0–M8 P0 implementation: deterministic browser
security controls, exact action revalidation, bounded three-tier detectors,
BYOK provider transports, provenance/source-to-sink and memory guards,
adversarial corpus/invariant/property coverage, offline examples, CLI P0
commands, and a local release-artifact pipeline.

The candidate must be rebuilt with `pnpm release:candidate` so its ignored
artifact manifest contains the current nine package hashes, SBOM hash, and
staged generated changelog hashes. The command installs the exact packed
artifacts offline in a temporary consumer and verifies public imports, schemas,
CLI secure-default commands, and a scanner-enabled quick start.

The remaining external release requirements are intentionally open in the
[v0.1 checklist](../release-checklist-v0.1.md): remote branch/ruleset and
workflow evidence, protected release environment/key custody, trusted publisher
mappings, fresh D-05 maintainer authorization, signed tag, npm provenance,
GitHub release/SBOM/attestation, and a post-publish consumer check.

Known capability limitations are unchanged: only documented Playwright route
hooks are enforceable; Stagehand network, WebMCP, and secret sinks are disabled
or unavailable; optional OpenCode guard construction is unavailable; semantic
outputs remain non-authoritative evidence; and deferred P1 work is not shipped
as v0.1 functionality.
